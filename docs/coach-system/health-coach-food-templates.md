# Health Coach Food Templates

Last updated: 2026-08-01

Purpose: reduce nutrition logging friction by turning Dylan's repeated foods/orders into reusable, source-marked templates.

Status: initial scaffold. Do not treat this as complete.

## Rules

- Restaurant/fast food: official nutrition first; verified source second; never silently estimate when official/verified source is needed.
- Home/known products: use known labels/Cronometer rows when available.
- Store calories, protein, carbs, fat, fiber when available.
- Store source and confidence.
- If Dylan changes an order, update the template rather than assuming same.
