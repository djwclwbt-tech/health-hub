# Health Coach Do-Not-Repropose List

Last updated: 2026-08-01

These are disqualified unless Dylan explicitly revives them.

## Nutrition/adherence

- Untracked weekends.
- Reduced-calorie structured weekends as default.
- Punitive undereating after deviations.
- Blind calorie cuts before nutrition completeness and weekend NEAT are understood.
- Wearable calorie burn for TDEE decisions.
- Generic meal-plan options menus.
- Treating blank nutrition as neutral.

## Training/injury

- Hack squats.
- KB swings.
- Aggressive hamstring stretching.
- Stretch-only mobility under barbell loading.
- Loaded squatting while SI flare is active or unknown.
- Coaching from app program state without reconciling handoff/body status.

## Coach behavior

- Spammy daily questionnaires.
- Dashboard commentary with no behavior change.
- Generic fitness/recovery advice.
- Long option lists.
- App features before operating model is stable.
- Autonomous writes/program changes before manual loop proves value and Dylan approves.
